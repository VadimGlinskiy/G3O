# Параметры DXVK в G3O

[← README](../README.md)

Это **все 127 разных ключей**, перечисленных в официальных `dxvk.conf` версий 1.10.1, 1.10.3, 2.4.1 и 3.0.1: соответственно 69, 69, 81 и 96. В `3.0.1-hdr` лежат те же DLL, что в `3.0.1`; отдельного HDR для Gothic 3 нет.

✓ означает «ключ есть в конфиге этой версии», а не «его нужно включить». Если ключ не задан, DXVK использует значение по умолчанию. Меняйте по одному ключу и сохраняйте рабочий файл. Параметры D3D11 к Gothic 3 не относятся; DXGI — преимущественно к D3D10/11, хотя подмена видеокарты может затронуть и D3D9.

На RX 570 не форсируйте `d3d9.samplerAnisotropy = 16`: она вызывала красную рябь; `-1` оставляет выбор игре. **Не включайте `d3d9.supportCubeDepthFormats`**: официальный конфиг DXVK прямо предупреждает о проблемах в Gothic 3. Ни один параметр ниже сам по себе не добавляет игре новые текстуры или HDR.

| Версия | Что изменилось для Gothic 3 |
| --- | --- |
| 1.10.1-async | Vulkan 1.1; экспериментальный async-форк. |
| 1.10.3-async | Добавлена `d3d9.seamlessCubes`, убрана `d3d9.allowLockFlagReadonly`. |
| 2.4.1 | Vulkan 1.3; новые LOD, ограничения памяти текстур и библиотеки конвейеров; без async. |
| 3.0.1 | Vulkan 1.4; новые параметры памяти/драйверов, ряд старых D3D9-ключей удалён. |

В сборках 1.10.x-async отдельно доступен `dxvk.enableAsync = true` ([документация форка](https://github.com/Sporif/dxvk-async)); в обычных DXVK 2.4.1/3.0.1 его нет. Ошибочные старые строки G3O `dxvk.trackPipelines`, `dxvk.enableHDR`, `d3d9.enableHDR`, `dxvk.logLevel` ни в одной из четырёх версий не являются параметрами этого каталога. Для уровня журнала есть переменная среды `DXVK_LOG_LEVEL`.
